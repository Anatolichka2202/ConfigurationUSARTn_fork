# Курс системного программирования

Полноценный практический курс системного программирования на языке C для Linux.

## Структура курса

| №  | Лекция                          | Задание                       |
|----|---------------------------------|-------------------------------|
| 01 | Введение                        | Hello, World через syscall    |
| 02 | Процессы и потоки               | Дерево процессов              |
| 03 | Управление памятью              | Собственный аллокатор         |
| 04 | Файловый ввод/вывод             | Копировщик файлов             |
| 05 | Сетевое программирование        | TCP echo-сервер               |
| 06 | Сигналы                         | Обработчик сигналов           |
| 07 | Системные вызовы                | Трассировка через ptrace      |

## Требования

- Linux (Ubuntu 22.04 или новее)
- GCC 11+
- POSIX-совместимая среда

## Сборка примеров

```bash
cd assignments/01-intro
gcc -o solution solution.c
./solution
```
