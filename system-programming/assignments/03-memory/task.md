# Задание 03: Собственный аллокатор памяти

## Цель

Реализовать упрощённый аллокатор памяти на основе `sbrk()`.

## Задача

Реализовать три функции:

```c
void *my_malloc(size_t size);
void  my_free(void *ptr);
void *my_calloc(size_t nmemb, size_t size);
```

### Требования к реализации

1. **my_malloc(size)**: выделить `size` байт на куче через `sbrk()`.
   - Хранить метаданные блока (размер, флаг занятости) перед полезными данными.
   - При повторном вызове **переиспользовать** ранее освобождённые блоки подходящего размера.

2. **my_free(ptr)**: пометить блок как свободный (не возвращать память ОС).

3. **my_calloc(nmemb, size)**: выделить `nmemb * size` байт и обнулить.

4. Написать тест:
   - Выделить массив из 100 `int`
   - Заполнить числами 0..99
   - Освободить
   - Выделить снова (должен переиспользоваться тот же блок)
   - Проверить, что адреса совпадают

## Структура заголовка блока

```c
typedef struct Block {
    size_t        size;
    int           free;
    struct Block *next;
} Block;
```

## Проверка

```bash
gcc -Wall -Wextra -o solution solution.c
./solution
```

Ожидаемый вывод:
```
malloc: выделено 400 байт по адресу 0x...
free: освобождено
malloc: выделено 400 байт по адресу 0x... (тот же адрес!)
calloc: выделено 200 байт, все нули: OK
Все проверки пройдены
```

## Запрещено

- Использовать стандартные `malloc`, `free`, `calloc`
- Использовать `mmap` (только `sbrk`)
