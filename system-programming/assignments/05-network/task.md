# Задание 05: TCP Echo-сервер

## Цель

Реализовать многоклиентский TCP echo-сервер с использованием `select()`.

## Задача

### Сервер (`server.c`)

Реализовать сервер, который:

1. Слушает на порту 7777 (TCP, IPv4)
2. Принимает несколько соединений **одновременно** через `select()`
3. Для каждого клиента — отправляет обратно всё полученное (echo)
4. При отключении клиента — корректно закрывает дескриптор
5. При получении SIGINT (Ctrl+C) — корректно завершается

### Клиент (`client.c`)

Реализовать клиент, который:

1. Подключается к `127.0.0.1:7777`
2. Отправляет строку, введённую пользователем
3. Получает эхо и выводит на экран
4. Повторяет до ввода `quit`

## Требования

- Сервер — **однопоточный**, использует `select()` для мультиплексирования
- Максимум 10 одновременных клиентов
- Сервер не должен зависать при отключении клиента
- Установить `SO_REUSEADDR`

## Проверка

```bash
# Терминал 1: сервер
gcc -Wall -Wextra -o server server.c
./server

# Терминал 2: клиент 1
gcc -Wall -Wextra -o client client.c
./client

# Терминал 3: клиент 2 (одновременно)
./client
```

Ожидаемый вывод сервера:
```
Сервер запущен на порту 7777
Клиент подключился: 127.0.0.1:54321
Клиент подключился: 127.0.0.1:54322
Echo [fd=4]: hello
Echo [fd=5]: world
Клиент отключился: fd=4
```

## Усложнение

Заменить `select()` на `epoll()` и проверить, что сервер работает корректно.
