# Задание 02: Дерево процессов

## Цель

Создать программу, которая строит дерево процессов с помощью `fork()` и выводит информацию о каждом процессе.

## Задача

1. Главный процесс создаёт **3 дочерних** процесса через `fork()`.

2. Каждый дочерний процесс:
   - Печатает своё PID и PID родителя
   - Выполняет "работу": считает сумму чисел от 1 до N (N — номер дочернего, умноженный на 1000000)
   - Завершается с кодом, равным номеру дочернего (1, 2 или 3)

3. Родительский процесс:
   - Дожидается **всех** дочерних процессов через `waitpid`
   - Выводит PID и код завершения каждого

## Требования

- Использовать `fork()`, `waitpid()`, `getpid()`, `getppid()`
- Нельзя использовать `system()` или `popen()`
- Все дочерние процессы должны быть корректно собраны (нет зомби)

## Проверка

```bash
gcc -Wall -Wextra -o solution solution.c
./solution
```

Ожидаемый вывод (PID будут другими):
```
[parent] PID=12345, ожидаю дочерних...
[child 1] PID=12346, PPID=12345
[child 2] PID=12347, PPID=12345
[child 3] PID=12348, PPID=12345
[parent] дочерний 12346 завершился с кодом 1
[parent] дочерний 12347 завершился с кодом 2
[parent] дочерний 12348 завершился с кодом 3
```

## Усложнение (по желанию)

Реализовать дерево глубиной 2: каждый из 3 дочерних создаёт ещё по 2 внука.
