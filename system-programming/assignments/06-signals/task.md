# Задание 06: Обработчик сигналов

## Цель

Написать программу-демон, которая корректно обрабатывает сигналы управления.

## Задача

Реализовать программу `daemon_sim`, которая:

1. **SIGTERM** — корректное завершение (сохранить "состояние" в файл `/tmp/daemon_state.txt`, затем выйти)

2. **SIGINT** — игнорировать первые 2 раза, на третий — завершиться как при SIGTERM

3. **SIGHUP** — перезагрузить конфигурацию (симулировать: вывести `"Конфигурация перезагружена"`)

4. **SIGUSR1** — вывести статистику: сколько секунд работает, сколько "задач" обработано

5. **SIGCHLD** — корректно собирать дочерние процессы (программа периодически fork'ает дочерних для "обработки задач")

### Основной цикл

Каждые 2 секунды программа:
- Создаёт дочерний процесс через `fork()`
- Дочерний выполняет "задачу" (sleep 1) и завершается
- Родитель собирает завершившихся дочерних через SIGCHLD

## Требования

- Использовать `sigaction()`, не `signal()`
- Не использовать `printf` внутри обработчиков сигналов
- Корректно работать с `volatile sig_atomic_t`

## Проверка

```bash
gcc -Wall -Wextra -o solution solution.c
./solution &
PID=$!

sleep 3
kill -HUP $PID       # перезагрузка конфига

sleep 2
kill -USR1 $PID      # статистика

sleep 2
kill -TERM $PID      # завершение

cat /tmp/daemon_state.txt
```

Ожидаемый вывод:
```
[daemon] PID=12345 запущен
[daemon] задача 1 завершена
[daemon] задача 2 завершена
[daemon] задача 3 завершена
[daemon] конфигурация перезагружена
[daemon] задача 4 завершена
[daemon] статистика: работаю 7 сек, обработано задач: 4
[daemon] получен SIGTERM, завершаемся...
[daemon] состояние сохранено в /tmp/daemon_state.txt
```
