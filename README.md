# ConfigurationUSARTn

Библиотека на языке C для настройки USART/UART и DMA на микроконтроллерах GD32F303 и GD32F450.

Библиотека предоставляет:

- настройку USART/UART;
- передачу и приём через DMA;
- работу с прерываниями USART и DMA;
- блокирующую передачу байта, буфера и строки.

## Поддерживаемые семейства

| Макрос | Семейство | Заголовочный файл SDK |
|---|---|---|
| `GD32F303_` | GD32F303xx | `gd32f30x.h` |
| `GD32F450_` | GD32F450xx | `gd32f4xx.h` |

В `ConfigurationUSARTn.h` должен быть включён только один макрос семейства:

```c
//#define GD32F303_
#define GD32F450_
```

Одновременное включение обоих макросов запрещено и приводит к ошибке компиляции.

## Важное ограничение

Библиотека не настраивает GPIO. До вызова функций USART необходимо настроить тактирование и выводы TX/RX в проекте платы.

Конкретные порты, выводы, альтернативные функции GPIO, DMA-каналы, субпериферии и IRQ необходимо проверить по reference manual именно используемого микроконтроллера, версии SDK и схеме платы. По одному исходному файлу библиотеки нельзя подтвердить правильность аппаратного соответствия для конкретной платы.

## Порядок использования

1. Подключить заголовочный файл.
2. Выбрать семейство GD32.
3. Настроить тактирование и GPIO в проекте.
4. Вызвать `ConfigUsart()`.
5. При необходимости настроить `ConfigUsartDMA_Tx()` и `ConfigUsartDMA_Rx()`.
6. Реализовать используемые обработчики прерываний в проекте.

При использовании DMA сначала вызывается `ConfigUsart()`, затем соответствующая функция DMA.

## Настройка USART

Для GD32F303:

```c
ConfigUsart(USART1, 115200, USART_MSBF_LSB, non, 1, 4);
```

Для GD32F450 дополнительно передаётся режим oversampling:

```c
ConfigUsart(UART7, 115200, USART_MSBF_LSB,
            USART_OVSMOD_8, non, 0, 5);
```

Параметр `configIrqn` является битовой маской. Доступные значения объявлены в `enum confInterrupt`:

- `non` — без прерываний;
- `receiveRBNE` — приём данных;
- `transmissionTBE` — пустой буфер передатчика;
- `transmissionTC` — завершение передачи.

## DMA

`ConfigUsartDMA_Tx()` передаёт данные из памяти в USART.

`ConfigUsartDMA_Rx()` передаёт данные из USART в память.

Параметр `circulationEnable` включает циклический режим DMA. Обработка циклического буфера и определение границ пакета остаются обязанностью проекта.

Параметр `iRQn` задаёт прерывания DMA и объявлен в перечислениях `enum confInterruptDMATransmit` и `enum confInterruptDMAReceiv`.

Тип буфера GD32F303 отличается от типа буфера GD32F450 в текущем API. Перед изменением этого API необходимо проверить вызывающий код и используемую версию SDK.

## Обработчики прерываний

Заголовочный файл содержит объявления обработчиков, но обработка данных должна быть реализована в проекте пользователя. В обработчике нужно проверить источник прерывания, обработать данные и очистить соответствующий флаг согласно документации SDK.

Универсальный обработчик для всех плат библиотека не предоставляет, поскольку логика обработки зависит от конкретного проекта, буфера и протокола обмена.

## Блокирующая передача

При включённом макросе `SENDING_VIA_USART` доступны функции:

```c
void Usart_send_byte(const uint8_t byte, const uint32_t usart_perith);
void Usart_send_buf(const void* const buf,
                    const uint32_t usart_perith,
                    const uint32_t len);
void Usart_send_string(const void* const str,
                       const uint32_t usart_perith);
```

Эти функции используют polling: процессор ожидает готовности USART после передачи каждого байта. Для больших объёмов данных следует рассмотреть DMA.

## Проверка перед использованием

Перед включением библиотеки в прошивку необходимо проверить:

- тактирование GPIO и USART;
- выбранные выводы и альтернативные функции;
- соответствие USART и DMA-канала;
- номер субпериферии DMA;
- имя IRQ в используемом SDK;
- порядок очистки флагов в обработчиках;
- тип и размер буфера;
- необходимость циклического режима;
- настройки baudrate и формата кадра.

Аппаратная проверка библиотеки на конкретной плате в этом репозитории не заявляется.
